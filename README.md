# Medical Diagnosis Knowledge Repository

Knowledge repository for the symptom-based medical diagnosis system built in Knowledge Engineering Experiments 1 and 2 (Experiment 3).

| File | Knowledge category |
|------|--------------------|
| `entities_relationships.json` | Entities, their attributes and the relationships between them |
| `diagnosis_rules.json` | IF-THEN production rules (disease and its symptom set) |
| `precautions.json` | Precaution advice for each disease |
| `sample_queries.json` | Test queries with their expected results |

For academic use only. Not a substitute for professional medical advice.
